# Static assets

All assets here are v1 assets or the owner's own art, copied (never moved) from the v1 project on 2026-10-04.
Source art that is not served lives in `assets_src/` at the repo root.

| Folder | Contents | Origin |
|---|---|---|
| `img/portraits/` | Class portraits (`*_cropped.png`), class icons (`*_p_icon.png`) for cleric, fighter, ranger, rogue, warlock, wizard; `scribe_cropped.png`, `shopkeeper_cropped.png` NPC art | owner's own art (v1) |
| `img/icons/conditions/` | 22 condition icons (prone, poisoned, stunned, blessed, ...) | v1 assets |
| `img/icons/equipment/` | Weapon and armor icons (longsword, shield, chain-mail, ...) | v1 assets |
| `img/icons/items/` | Gold, gem, key, potion, scroll, camp supplies, generic item | v1 assets |
| `img/icons/spells/` | Damage-school spell icons (fire, frost, radiant, ...) | v1 assets |
| `img/icons/stats/` | Six ability score icons (str, dex, constitution, int, wis, cha) | v1 assets |
| `img/icons/tabs/` | Phone tab icons, normal and `_active` (feed, map, player, scribe, shopkeeper, spellbook) | v1 assets |
| `img/ui/` | Backgrounds (stone, vellum, lobby), dice overlay, logos, favicon, AC shield, grit overlay, corner ornament | v1 assets |
| `audio/music/` | `defeat.mp3`, `victory.mp3` stingers. `ambient.mp3` and `combat.mp3` were over 15 MB and are NOT copied (see docs/DECISIONS.md) | v1 assets |
| `audio/scribe_intro.mp3` | Narrated intro line for the Scribe | v1 assets |
| `fonts/` | `Jersey10.ttf` plus its OFL licence text | Jersey 10, SIL OFL |

`assets_src/portraits_src/` holds the uncropped source portraits; `assets_src/dnd_ui/` holds the owner's UI kit
(frames, banners, buttons, character art, icon sets, music and voice clips). Neither is served.
